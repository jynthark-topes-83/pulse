# Pulse

[![Open Pulse app](https://img.shields.io/badge/Open%20App-Pulse-brightgreen?style=for-the-badge)](https://jynthark-topes-83.github.io/pulse)

Pulse is a minimal ritual counter built with plain HTML, CSS, and JavaScript.

## Features

- Create and manage named counters
- Tap, double-tap, swipe, and hold gestures
- Multiple visual atmospheres
- Milestone and max-limit feedback
- Web Audio API sound effects
- Hidden `jynthark overdrive` easter egg

## Run locally

Open `index.html` in a browser.

No build step and no dependencies are required.

## Notes

Counter data is saved in the browser with `localStorage`.
